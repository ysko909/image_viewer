# 要件定義書

## 目的

`app/static/img` ディレクトリに保存されている画像ファイルの一覧をWebページに表示し、各画像をクリックすると専用のページで大きく表示する。さらに、画像表示ページからスライドショーを開始できるようにする。

## 機能

- `/images` のようなURLにアクセスすると、画像ファイル一覧ページが表示される。
- ページには、`app/static/img` ディレクトリ内のすべての画像ファイル名がリスト形式で表示される。
- 各ファイル名は、画像表示ページへのリンクとする。
- `/image/<filename>` のようなURLにアクセスすると、指定された画像ファイルが表示されるページが表示される。
- 画像表示ページにスライドショーを開始するボタンを追加する。
- スライドショー機能:
    - 画像および動画（.mp4等）の再生に対応する。
    - 画像は１ファイルにつき設定された時間表示し、一定時間経過後は次のファイルを表示する。
    - 動画は全画面表示ではなく通常のスライドショー表示のまま（インライン）でミュート（消音）自動再生する。
    - 動画再生完了時（またはエラー・再生失敗時のフォールバック設定時間経過時）に自動で次のメディア（画像または動画）へ遷移する。
    - スライド切り替え時に動画のロード・再生を確実にクリーンアップし、残存するフルスクリーン表示があれば自動解除する。
    - スライドショーの表示時間は設定ページから変更可能とする。
    - スライドショー対象のメディア拡張子を設定ページから変更可能とする（保存フォルダ内の実在メディア拡張子を動的に検出して選択）。
    - 最後のファイルを表示し終わったら、設定に応じて一覧表示に戻るか最初からループ再生する。
    - 表示順はファイル名順、またはシャッフル設定に応じた順序とする。
    - スライドショー再生時、スムーズな表示切替のために次（および前）の画像ファイルをバックグラウンドで事前読み込み（プリロード）する。
    - 操作性強化:
        - キーボードショートカット（左右キーで前へ/次へ、Spaceキーで再生/一時停止、Fキーで全画面切り替え）に対応する。
        - 画面上で全画面表示（フルスクリーン）のオン/オフを切り替え可能とする。
        - スライドショー再生中に表示時間（速度）を即座に変更できるUIを提供する。
        - 現在の表示位置と総枚数を表すインジケーター（例: `3 / 24`）を表示する。
- サムネイル生成・表示機能:
    - 画像一覧ページで各メディアのサムネイルをグリッド表示する。
    - サムネイル画像はオンデマンドで自動生成・キャッシュし、不要な通信量や読み込み遅延を削減する。
- 一覧探索・ページネーション機能:
    - ファイル名によるキーワード検索（絞り込み）に対応する。
    - ソート順の変更（ファイル名昇順/降順、更新日時新しい順/古い順、ファイルサイズ大/小）に対応する。
    - ページネーション（1ページあたりの件数設定・ページ移動）に対応し、大量ファイル時の描画負荷を低減する。
- メディア詳細情報表示機能:
    - 個別表示ページ（`/image/<filename>`）において、ファイルサイズ、更新日時、画像解像度（幅×高さ）、ファイル形式等のメタデータを分かりやすく表示する。
    - 一覧ページ上でも各カードにファイルサイズ等の補足情報を表示する。

## 想定ユーザー

- アプリケーションの管理者または開発者

# 設計書

## 概略設計

- Flaskアプリケーションに `/images` ルートと `/image/<filename>` ルート、そしてスライドショー用の新しいルートを追加する。
- `/images` ルートでは、`app/static/img` ディレクトリの内容を読み取り、ファイル名のリストを取得する。
- `/images` ルートは、取得したファイル名のリストを `image_list.html` テンプレートに渡し、画像表示ページへのリンクを含む一覧を生成する。
- `/image/<filename>` ルートでは、指定されたファイル名を `image_display.html` テンプレートに渡し、画像または動画を表示する。
- スライドショー用のルートでは、メディアファイル（画像・動画）のリストを取得し、JavaScriptを使用してインラインで動画の自動再生および設定時間ごとの画像切り替えを行う。
- スライドショーの表示時間を設定するためのルートとテンプレートを提供する。

## 機能設計

### ルート `/images`

- HTTPメソッド: GET
- クエリパラメータ:
    - `q`: 検索キーワード（ファイル名の部分一致）
    - `sort`: ソート順（`name_asc`, `name_desc`, `date_desc`, `date_asc`, `size_desc`, `size_asc`）
    - `page`: ページ番号（整数、デフォルト 1）
    - `per_page`: 1ページあたりの件数（整数、デフォルト 24）
- 処理内容:
    1. `app/static/img` ディレクトリのパスを取得する。
    2. 指定されたディレクトリ内のファイル一覧を取得する。
    3. 取得したファイル一覧から、対応メディアファイルをフィルタリングする。
    4. クエリパラメータ `q` が指定されている場合、ファイル名で絞り込みを行う。
    5. クエリパラメータ `sort` に基づき、ファイル名・更新日時・ファイルサイズでソートを行う。
    6. `page` と `per_page` に基づいてページネーションを行い、現在のページのアイテムリストとページネーション情報を `image_list.html` テンプレートに渡してレンダリングする。
- レスポンス: 画像・動画ファイル一覧を表示するHTMLページ

### ルート `/image/<filename>`

- HTTPメソッド: GET
- パラメータ: `<filename>` (表示する画像・動画ファイル名)
- 処理内容:
    1. パラメータとして受け取ったファイル名を `image_display.html` テンプレートに渡し、画像または動画を表示する。
    2. スライドショー開始ボタンのリンク先として、スライドショー用のルートにファイル名を渡す準備をする。
- レスポンス: 指定されたメディアファイルを表示するHTMLページ

### ルート `/slideshow/<filename>`

- HTTPメソッド: GET
- パラメータ: `<filename>` (スライドショーを開始するメディアファイル名)
- 処理内容:
    1. 現在設定されているスライドショー対象拡張子（`SLIDESHOW_EXTENSIONS`、未設定時は検出全拡張子）を取得する。
    2. 指定されたファイルの拡張子が対象拡張子に含まれていない場合、警告メッセージ（「この拡張子はスライドショー対象外に設定されています」）を表示して `/image/<filename>` へリダイレクトする。
    3. `app/static/img` ディレクトリ内の対象拡張子に一致するメディアファイル一覧を取得し、ソートまたはシャッフルする。
    4. パラメータで指定されたファイル名からスライドショーを開始するための開始位置を特定する。
    5. メディアファイルリストと設定値（表示時間、ループ、開始位置等）をテンプレートに渡す。
- レスポンス: スライドショーを表示するHTMLページ

### ルート `/slideshow`

- HTTPメソッド: GET
- クエリパラメータ: `dirs`, `recursive`
- 処理内容:
    1. 現在設定されているスライドショー対象拡張子に基づき、指定フォルダ内の対象メディアファイル一覧を取得する。
    2. シャッフル設定を反映し、スライドショーを表示する。
- レスポンス: スライドショーを表示するHTMLページ

### ルート `/slideshow/config`

- HTTPメソッド: GET
- 処理内容:
    1. 現在のスライドショー表示時間、ループ設定、シャッフル設定を取得する。
    2. `UPLOAD_FOLDER` 内を走査し、実在するメディア拡張子の一覧を動的に検出する。
    3. 現在選択されている対象拡張子設定（未設定時は検出全拡張子）を取得する。
    4. 取得した設定値および検出拡張子一覧を `slideshow_config.html` テンプレートに渡してレンダリングする。
- レスポンス: スライドショー設定ページを表示するHTMLページ

### ルート `/slideshow/config/save`

- HTTPメソッド: POST
- 処理内容:
    1. POSTデータから表示時間（ミリ秒）、ループ設定、シャッフル設定、選択された拡張子一覧を取得する。
    2. 入力値のバリデーション（表示時間は500ミリ秒以上、選択拡張子は1つ以上必須）。
    3. アプリケーション設定（`SLIDESHOW_DURATION`, `SLIDESHOW_LOOP`, `SLIDESHOW_SHUFFLE`, `SLIDESHOW_EXTENSIONS`）として保存し、設定ページにリダイレクトする。
- レスポンス: スライドショー設定ページへのリダイレクト

### ルート `/thumbnail/<path:filename>`

- HTTPメソッド: GET
- パラメータ: `<filename>` (サムネイルを取得するメディアファイル名)
- 処理内容:
    1. `app.config['UPLOAD_FOLDER']` 内の対象ファイル存在確認および `os.path.normpath` によるディレクトリトラバーサル検証。
    2. 画像ファイルの場合、キャッシュフォルダ（`app.config['THUMBNAIL_FOLDER']`）に対象サムネイルが存在するか確認。
    3. キャッシュが存在しない場合、Pillow (`PIL.Image`) を用いてアスペクト比を維持したサムネイル（デフォルト128x128）を生成し、キャッシュへ保存。
    4. 動画ファイル（`.mp4`, `.webm`, `.mov`, `.m4v` 等）や画像生成不可の場合は、デフォルトのプレースホルダーアイコン（拡張子名表示SVG）または適切なレスポンスを返却。
    5. サムネイルファイルを `send_file` でクライアントへ返却。
- レスポンス: サムネイル画像（JPEG/PNG等）

### テンプレート `image_list.html`

- ベーステンプレート: `layout.html` を継承する。
- 表示内容:
    - ページタイトル: "画像ファイル一覧"
    - `app/static/img` ディレクトリ内のメディアファイル名をリスト表示する。
    - 各リスト項目は、ファイル名とメディア表示ページへのリンク (`/image/<ファイル名>`) を含む。

### テンプレート `image_display.html`

- ベーステンプレート: `layout.html` を継承する。
- 表示内容:
    - ページタイトル: "メディア表示"
    - 指定されたメディアファイル（画像 `<img>` または動画 `<video>`）を表示する。
    - メディア詳細情報（ファイルサイズ、更新日時、解像度/寸法、形式）をカード形式で丁寧に表示する。
    - 一覧ページに戻るリンクおよびスライドショー開始リンクを含む。

### テンプレート `slideshow.html`

- ベーステンプレート: `layout.html` を継承する。
- 表示内容:
    - ページタイトル: "スライドショー"
    - 画像表示領域（`<img>`）および動画表示領域（`<video>`）を備える。
    - `<video>` 要素には `playsinline`, `webkit-playsinline`, `muted`, `autoplay` を指定し、全画面化せずインライン・消音で自動再生する（対応拡張子: `mp4`, `webm`, `mov`, `m4v`）。
    - JavaScript制御:
        - 画像表示時: 設定時間（`duration`）経過後に `nextImage()` を呼び出して次のメディアへ進む。
        - 動画表示時: `muted = true`, `defaultMuted = true`, `playsInline = true` を設定して自動再生を実行。動画終了（`ended`）で自動的に次のメディアへ進む。
        - 動画再生が失敗（自動再生ブロック、ロードエラー等）した場合、スライドショー停止を防ぐため設定時間後に次のメディアへ自動遷移するフォールバックタイマーを設定する。
        - スライド切り替え時に動画の停止・リソース解放を行い、残存フルスクリーンの自動解除（`exitFullscreen`）を行う。
        - 「一時停止/再生」ボタンおよび「前へ/次へ」ナビゲーション操作に対応する。
        - キーボードイベント（ArrowLeft/ArrowRight, Space, 'f'）による操作に対応する。
        - 全画面表示トグルボタン（HTML5 Fullscreen API）を提供する。
        - 画面上での表示間隔調整ドロップダウン（1秒〜10秒）を備え、リアルタイムに切り替え可能とする。
        - スライドインジケーター（現在位置 / 全体数）を表示する。

### テンプレート `slideshow_config.html`

- ベーステンプレート: `layout.html` を継承する。
- 表示内容:
    - ページタイトル: "スライドショー設定"
    - 表示時間、ループ有無、シャッフル有無、対象ファイル拡張子のチェックボックス選択フォーム。
    - フォルダ内にメディアファイルが存在しない場合のメッセージ案内。

## クラス構成

既存の `app.py` のルート関数を使用。

- `app.py`:
    - `index()` 関数
    - `image_list()` 関数: `/images` ルート
    - `image_display()` 関数: `/image/<filename>` ルート
    - `slideshow()` 関数: `/slideshow/<filename>` ルート
    - `slideshow_custom()` 関数: `/slideshow` ルート（フォルダ指定・再帰対応）
    - `slideshow_config()` 関数: `/slideshow/config` ルート
    - `save_slideshow_config()` 関数: `/slideshow/config/save` ルート
